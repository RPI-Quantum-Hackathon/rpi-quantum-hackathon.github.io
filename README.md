# RPI Quantum Hackathon Website

This is a simple, static landing page for a student-led quantum computing hackathon hosted by the RPI Quantum Computing Club.

## Structure

- `index.html` – main single-page site with sections for hero, about, schedule, FAQ, sponsors, and apply.
- `styles.css` – modern dark, quantum-themed styling and responsive layout.
- `script.js` – small enhancements (mobile nav toggle and FAQ accordion).

## Running the site

Open `index.html` in any modern browser:

1. In your file explorer, navigate to where you cloned the repository.
2. Double-click `index.html` (or right-click and choose "Open with" → your browser).
